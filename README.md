# Cat Nyam

귀여운 고양이가 떨어지는 츄르를 잡아 점수를 얻는 정적 미니게임입니다.

## 실행

Vercel에 배포하면 서버 API와 함께 실행됩니다. 로컬 파일로 직접 열면 서버 랭킹과 로그인 API는 동작하지 않습니다.

## 기능

- 아이디, 닉네임, 비밀번호, 비밀번호 확인으로 계정 생성
- 새로 열면 로그인/회원가입 화면부터 표시
- 45초 동안 츄르를 잡아 점수 획득
- 게임 화면 옆에 계정별 최고 점수와 상위 10명 랭킹 표시
- 로그인 후 우측 상단 닉네임 클릭으로 계정 설정 팝업 열기
- 계정 설정 팝업에서 아이디, 닉네임, 비밀번호 변경
- 관리자 계정은 계정 설정 팝업에서 계정 관리 가능
- 관리자 계정은 전체 츄르 랭킹 초기화 가능
- 우다다, 숨숨집, 골골송 모드 아이템

## 관리자

처음 가입한 계정이 관리자 권한을 받습니다. 관리자가 일반 계정 비밀번호를 초기화하면 임시 비밀번호가 화면에 표시됩니다.

## 서버 설정

1. Supabase 무료 프로젝트를 만듭니다.
2. Supabase SQL Editor에서 `supabase/schema.sql` 내용을 실행합니다.
3. Vercel Project Settings > Environment Variables에 아래 값을 추가합니다.

이미 운영 중인 Supabase 프로젝트에도 닉네임 컬럼을 추가하려면 `supabase/schema.sql` 내용을 다시 실행하면 됩니다.

```text
SUPABASE_URL
SUPABASE_SECRET_KEY
SESSION_SECRET
```

`SUPABASE_SECRET_KEY`는 브라우저에 넣지 말고 Vercel 환경변수에만 저장해야 합니다.

## 조작

- 오른쪽 이동: `→` 또는 `D`
